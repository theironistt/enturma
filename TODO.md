# Enturma — entregas

- [x] **Base executável:** React + TypeScript + Vite, CSS puro, Lucide React, scripts de desenvolvimento, build e testes; deploy estático compatível com Vercel.
- [x] **Início e onboarding:** tela inicial com wordmark, frase, nova noite, como jogar, continuação e exclusão confirmada de partida salva.
- [x] **Criação da noite:** nome, modos Social/Ousado/Capetinha Roxo, confirmação curta do modo roxo, 2–12 participantes, cores e validação.
- [x] **Catálogo:** pelo menos 100 desafios reais, com as dez categorias pedidas, quatro dificuldades, pontos, modos, elegibilidade de extra e campo active.
- [x] **Painel compartilhado:** cartão independente por pessoa com nome, cor, pontuação, missão, dificuldade, progresso, espaços, passes e status.
- [x] **Motor de regras:** 10 espaços por pessoa; conclusão pontua e avança; três passes substituem sem consumir espaço; depois dos passes, pular consome espaço sem substituição; jogadores avançam de forma independente.
- [x] **Sorteio:** sem repetição por jogador, evita categoria/dificuldade consecutivas quando possível, progressão de dificuldade e Carta Extra ousada/épica com fallback seguro.
- [x] **Pontuação:** Fácil 10, Média 20, Ousada 30, Épica 50; bônus de primeiro, sequência de três, cinco e dez conclusões e Carta Extra; sem penalidades.
- [x] **Carta Extra:** desbloqueia somente com 10/10 concluídos, é opcional, única, roxa, sem passe e não altera a meta regular.
- [x] **Carta Extra consumível:** após concluir ou recusar, a carta é encerrada, limpa da partida e não pode ser reaberta para pontuar novamente.
- [x] **Desafios coletivos:** catálogo local com 15 opções; o painel permite girar uma missão para toda a roda, marcar exatamente quem concluiu, conceder pontos apenas aos marcados e encerrar a missão sem consumir espaços individuais.
- [x] **Histórico e ranking:** concluídos, trocados, pulados, bônus, extra; ordenação por pontos, concluídos, espaços pulados e cadastro.
- [x] **Finalização:** jogador pode terminar independentemente; noite termina quando todos terminam ou anfitrião encerra; tela final com vencedor e destaques.
- [x] **Persistência/offline:** partida, catálogo em bundle, localStorage, manifesto e service worker; restauração após atualização e reabertura.
- [x] **Qualidade:** testes Vitest para regras essenciais, README com execução, build, Vercel e checklist manual.
- [x] **Direção visual refinada:** linguagem preta e clean inspirada no Vercel, com superfícies quase pretas, bordas finas, baixo uso de gradientes e destaque monocromático.
